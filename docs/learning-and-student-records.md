# 수업 자료 분석과 학생 기록

## 수업 분석과 커리큘럼의 흐름

1. 수업 분석 메뉴에서 선생님 프로필을 등록한다. 분석은 프로필별로 분리하며 특정 강사의 성향·과목·교재·일정을 기본값으로 고정하지 않는다.
2. 강의 영상을 선택하면 채널 소유자 권한으로 자막을 읽는다. Claude가 제시한 발언 인용을 자막과 대조하고, 유효한 근거만 네 가지 축과 수업 구간·속도 추정에 사용한다. 자막으로 보이지 않는 판서·학생 활동·숙달 정도는 확정하지 않는다.
3. 저장한 교재 PDF에서 최대 20쪽씩 범위를 선택한다. 원본 파일을 수정하지 않고 필요한 페이지만 나누어 Claude에 전달한다. 결과에는 원본 PDF 쪽수·읽은 구절·확인한 문제 수를 저장한다. 쪽수는 검증하지만 이미지 속 인용의 정확성은 선생님의 검토가 필요하다. 읽지 않은 부분은 전체 분석으로 표시하지 않는다.
4. 커리큘럼에서 선생님·반·교재 분석 범위·해당 반의 수업 분석·목표·기간·수업 시간·특이사항을 선택한다. AI는 근거를 연결한 예상 시간을 제안한다. 실제 날짜 배분과 부족 시간·보강 후보는 정규 요일·휴강·보강을 적용한 별도 계산으로 구한다.
5. AI는 완료 진도를 확정하지 않는다. 재계획 때 같은 단원의 확인된 진도를 보존하고, 이름이 바뀐 기존 완료 단원도 임의로 삭제하지 않는다. 초안 검토 후 명시적으로 저장하며, 수정 충돌이 있으면 덮어쓰지 않는다.
6. 계획에서 자동 갱신을 켠 경우, 같은 선생님·반의 새 수업 분석이 완료되면 남은 계획의 새 초안을 접수한다. 저장한 계획은 검토 전까지 유지한다. 자동 갱신은 기본적으로 꺼져 있으며 추가 Claude 사용료가 발생한다.

동일 자료의 기존 분석은 기본적으로 재사용한다. 다시 분석을 명시하면 새 결과를 저장하고, 유형 집계에는 선생님·영상별 최신 결과만 사용한다. 서버 재시작으로 중단된 유료 분석은 자동으로 재실행하지 않는다.

프로필은 분석 자료를 나누는 단위다. 현재 선생님 관리자 로그인은 공유 관리 영역의 모든 프로필을 볼 수 있다. 별도 기관에 제공하는 서비스로 확장하려면 기관별 소유권과 계정 권한을 별도로 구현해야 한다.

## 학생 기록

학생 화면의 접속 알림을 서버에서 검증하고 접속 회차·영상별 시청 시간을 비공개 저장한다. 재생 위치와 시청 시간은 다른 값이다. 시청 시간은 이전에 화면이 보이고 재생 중이었던 짧은 구간의 실제 경과 시간을 추정하므로 건너뛴 영상 길이를 더하지 않는다. 정지·다른 화면·긴 연결 공백은 누적하지 않는다. 로그아웃·화면 종료를 구분하며, 알림이 끊기면 마지막 확인 시각으로 종료를 추정한다.

유튜브 이동은 풀이로그의 `유튜브에서 열기` 버튼 클릭만 기록한다. 유튜브 iframe 내부 로고 클릭이나 외부 앱에서 이후 시청한 시간은 확인할 수 없다. 학생 화면에도 기록 수집 안내를 표시한다. 기능 적용 이전의 기록을 소급 생성하지 않는다.

기록은 기존 비공개 설정 저장소에 별도 이름 공간으로 저장한다. 일반 설정·교재·분석 목록 조회에서는 제외하고, 학생 기록 메뉴에서 날짜와 학생을 제한해 읽는다. 조회 API는 선생님만 사용할 수 있으며 원본 인증값·세션 식별 정보·전화번호를 반환하지 않는다. 추가 SQL 설치는 필요 없다.

## 긴 타임라인 응답의 복구

타임라인 분석은 자막을 최대 10분·400개 항목·약 45KB 단위로 나누고 앞뒤 자막을 문맥으로 제공한다. 출력 길이/문맥 한도로 잘리거나 항목 수 상한에 닿은 구간만 더 작게 분할한다. 분석 거절·인증·사용 한도·통신 오류는 자동 반복하지 않는다. 요청 수와 분할 깊이에 상한을 두며, 불완전한 JSON은 타임라인으로 채택하지 않는다.

검증을 통과한 구간과 분할 정보는 비공개 저장한다. 같은 영상 정보·모델·분석 규칙·자막 구간이면 재시도나 서버 재시작 후에도 완료 구간을 재사용한다. 자막/모델/규칙이 달라지면 다른 결과로 취급한다. 전체 병합과 근거 검증이 끝나기 전에는 기존 초안과 공개 타임라인을 변경하지 않는다. 이 저장은 AI 분석 구간의 재사용이며, 유튜브 자막을 다시 가져올 때의 유튜브 API 한도까지 없애는 기능은 아니다.

## 이어보기·통합 검색·학생 질문·AI 사용 관리

- 학생 팝업에 서버에 저장된 본인 영상별 재생 위치로 이어보기 버튼을 표시한다. 20초 간격 및 상태 변경·닫기·이탈 때 위치를 저장한다. 강제 종료 시 마지막 저장 이후 위치는 남지 않을 수 있다. 유튜브 외부 시청 위치는 알 수 없다.
- 위치는 본인 학생 세션으로만 조회한다. 현재 반에 배정된 공개 영상만 허용하며, 응답에 내부 기기 ID를 반환하지 않는다. 같은 기기의 늦게 도착한 heartbeat는 이전 위치를 덮어쓰지 않는다.
- 검색은 학생에게 제공된 공개 영상의 제목·교재·과목·단원과 공개 타임라인 설명을 대상으로 한다. 제목 / 타임라인 결과를 분리하고 타임라인 결과는 해당 시작 시각으로 팝업을 연다. AI 호출이 없다.
- '이 부분 모르겠어요'는 현재 영상 시각을 고정하고 선택 메모를 받는다. 같은 학생·영상의 미확인 질문 중 15초 이내 항목은 중복 접수를 막는다. 선생님 첫 화면에서 미확인/확인 완료를 전환한다. 문자나 외부 메신저로 전송하지 않는다.
- `youtube_resume_`, `youtube_question_`, `youtube_ai_call_` 자료는 일반 settings 목록에서 제외한다. 서비스 역할로 서버를 통해서만 접근하며 신규 SQL은 필요 없다.
- AI 요청 관리 래퍼는 타임라인·수업 유형·PDF·커리큘럼의 실제 Claude 호출을 기록한다. API 요청 전에 예약을 저장하므로 실패·잘린 응답도 일일 요청 상한에 포함한다. 기본 0은 제한 없음이며 선생님이 연동 설정에서 지정한다. 날짜는 한국시간 자정에 바뀐다.
- 429 응답 후 Retry-After 또는 기본 5분 동안 새 Claude 호출을 차단한다. 자동으로 유료 재시도하지 않는다. 일괄 타임라인의 후속 작업은 자막 다운로드 전에도 상한/대기를 검사한다. 완료 구간 캐시 재사용은 기존과 같다.
- 모델별 입력/출력 100만 토큰당 단가를 선생님이 입력하면 이후 응답의 사용량으로 달러 비용을 추정한다. 단가 미설정, API 미응답, 프롬프트 캐시 토큰이 있는 응답은 비용을 임의 추정하지 않는다. API 응답 완료와 최종 초안 검증 성공은 별개다. 실제 청구액·잔액·금액 상한은 Claude Console 기준이며, 이 기능은 요청 횟수 상한이다. 배포 이전 사용량은 소급 집계하지 않는다.

학생 기록 화면은 반별 접기 → 학생별 접기 → 접속·영상 상세 순으로 표시한다. 조회 기간에 기록이 없는 등록 학생도 0분으로 포함한다. 누적 시청 시간 오름/내림차순과 이름순을 제공하고, 전체 학생 보기는 반 구분 없이 정렬한다. 누적 수치는 기존 조회 기간 기준이며 전체 기간을 소급 합산하는 기능은 아니다. 검색·정렬 변경 시 펼친 상태를 유지한다.

## Motion 화면 효과

Motion 14.9.0 mini를 `public/motion-vendor.js`에 로컬 번들로 포함한다. `npm run build:motion`으로 재생성하며 MIT 고지는 `public/motion-LICENSE.txt`에 보관한다. 외부 CDN이나 서버 AI 호출을 사용하지 않는다.

팝업 열기 220ms / 닫기 120ms, 반·학생 기록 접기 200ms, 즐겨찾기 저장 성공 반응 240ms를 적용한다. 팝업 전환 세대와 펼침 상태를 추적해 빠른 반복 입력·교체 시 이전 효과가 새 화면을 지우지 않도록 한다. 닫기를 누르면 영상 추적을 즉시 종료하고 마지막에 원래 버튼으로 포커스를 되돌린다. `prefers-reduced-motion: reduce` 또는 Motion 로드 실패 시 기본 동작으로 돌아간다.
